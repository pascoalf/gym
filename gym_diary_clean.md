# Gym diary — October 2026

## How to read this diary

- Each row is one set. Weights are in kg.
- Target reps are the planned reps per set; actual reps appear only when recorded or reasonably inferred.
- “—” means not recorded. It does not confirm that the target was completed.
- Easy / Moderate / Hard translate fácil / médio / difícil.
- Pull-up weights are **assistance**: less weight means less assistance.
- Left / Right refer to each arm. Curl weights are assumed to be per dumbbell.
- Cable triceps extension combines “Cable Pull extension”, “Cabo”, “Cabo extensão”, and “Cabo Pull”. Chest fly combines “Aberturas”.
- All dates are treated as 2026, based on the explicit final date. “21 novembro” is corrected to 21 October, as confirmed.
- Inferences and ambiguous entries are marked in the notes. The original diary is preserved in `gym_diary.txt`.
